Add your products

Scoop reads a few extra product fields called metafields. They give each product its color, flavor name and tagline.

Step 1: create the fields

Do this once. Go to Settings → Custom data → Products → Add definition. Create each field below. Type the namespace and key exactly.

NameNamespace and keyTypeWhat it does
Accent colorcustom.accent_colorColorThe product's color. Used on cards, the product page and the cart.
Flavorcustom.flavorSingle line textShort name, like "Black Cherry".
Taglinecustom.taglineSingle line textOne short line under the title.
Other flavorscustom.siblingsProduct (list)The products shown as flavor links.

One product, many flavors? Create the same Accent color field under Custom data → Variants. Each flavor variant then gets its own color.

All fields are optional. Without an accent color, the product uses the highlight color from Theme settings.

Step 2: fill them in

  1. Open a product in Products.
  2. Scroll to Metafields at the bottom.
  3. Pick a color, then type the flavor and tagline.
  4. Save.

Product images

  • Use PNG images with a transparent background. They sit on the colored background best.
  • Keep all products the same size and angle.
  • Videos and 3D models work too. Add them like normal media.

Color swatches

Want color dots instead of text buttons for options? Open the option in the product (like "Color"), link it to a category metafield, and set a color or image per value. Scoop shows them as swatches.

Star ratings

Install any review app that fills Shopify's standard rating fields (reviews.rating). The Star rating block then shows the stars.
